          Lock Nook in place

          iPhone can keep you inside one app until you enter a passcode. Set it up once:

          1. Open Settings › Accessibility › Guided Access and turn it on.
          2. In Passcode Settings, turn off Face ID (or Touch ID) so only the passcode can end it.
          3. Tap Set Guided Access Passcode and enter exactly this code:
          4. Write it on paper and leave it in another room, so getting out means getting up. Text it to a parent or friend too, so a lost note can't lock you in.
          5. In Nook, triple-click the side button, then tap Start.

          Nook keeps a spare copy under Settings › Spare key. During a focus session it takes a 5-minute wait to see it (or an emergency hold), so it's there if you need it but slow if you're just restless.
