# Paintings

The background paintings in this folder are by みんちりえ (Minchirie), https://min-chi.material.jp/.
Nook uses them under Minchirie's terms, which allow use in apps and games (commercial use and
editing included) but not redistributing the images as material.

They are **not** Nook's own work and aren't offered for reuse here. Please don't copy them out
of this repository for other projects. If you'd like to use them, download them from Minchirie's
site and follow the terms on each material's page.
